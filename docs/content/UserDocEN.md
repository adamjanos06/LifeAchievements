# LifeAchievements – User Documentation

## Overview
**LifeAchievements™** is a gamified goal-tracking website that allows you to complete real-life goals, tasks, and challenges which are organized into categories.
Every completed achievement grants a reward (XP) and appears on the **My Achievements** page.

The purpose of the application is to help you stay motivated in your personal development while visually tracking your progress across multiple areas of life.

---

## Getting Started

### Home Page
The home page introduces the features and purpose of the application. From here you can access two main paths:

- **GET STARTED**
  - Log In – Log in with an existing user account.
  - View Achievements – Browse achievements without an account.
- Navigation via the top menu:
  - Log In – Log in with an existing account.
  - Sign Up – Create a new user account.

---

## Registration and Login

### Registration
To register:
1. Go to the **Sign Up** page.
2. Enter the following information:
   - username
   - email address
   - password
   - password confirmation
3. Click the **Create Account** button.

![Sign up](https://cdn.imgchest.com/files/0b43093625c1.png)

After a successful registration, the system automatically logs you in.

### Login
To log in:
1. Go to the **Log In** page.
2. Enter your email and password.
3. Click the **Log In** button.

![Log in](https://cdn.imgchest.com/files/00e33172b893.png)

If the information is incorrect, the system displays an error message.

### Logout
You can log out using the red **Log Out** button on the **Profile** page.

---

## Navigation

The top navigation bar includes the following elements:

- **LIFE ACHIEVEMENTS** – located on the left, navigates back to the home page.
- **Catalog** – browse categories.
- **My Achievements** – view completed achievements in a mixed list.
- **Profile** – view profile information.

On mobile devices, these appear in a dropdown menu.

---

## Catalog

On the **Catalog** page you will see:

![Catalog](https://cdn.imgchest.com/files/96309c31267e.png)

### Category List
Each category contains:
- an icon
- name
- clickable card

### Selecting a Category
Clicking a category displays:
- category name
- list of achievements belonging to it

![Achievements](https://cdn.imgchest.com/files/2746ad8f2c5a.png)

### Viewing an Achievement
Click an achievement card to open a detailed modal:
- name
- description
- XP reward
- category icon

![Achievement](https://cdn.imgchest.com/files/c2859960459c.png)

---

## Completing an Achievement

Inside the modal window you will find:
- **MARK AS COMPLETED** button (if not completed yet)
- **COMPLETED** button turns grey when already done

After successful completion:
- A green checkmark appears in the top-right corner of the achievement
- The button becomes inactive
- The achievement appears on the **My Achievements** page

![AchievementCompleted](https://cdn.imgchest.com/files/3ab95ac84e79.png)

Achievements can only be completed once — duplicates are not allowed.

---

## My Achievements

On this page:
- previously completed achievements are listed
- category icons are displayed
- a green checkmark is shown on each item
- maximum of 9 items appear per page
- pagination appears if you have more than 9 achievements

![MyAchievements](https://cdn.imgchest.com/files/8036d36699da.png)

If the list is empty, the system displays:
> "You haven’t completed any achievements yet."

---

## Profile Page

The **Profile** page displays the following information:
- username
- email address
- user ID

If you are not logged in:
- a warning message appears
- a link to the login page is provided

The profile page includes:
- **Log Out** button – logs you out of the system

![Profile](https://cdn.imgchest.com/files/0383dc09c99d.png)

---

## Theme Switching (White / Dark Mode)

When pressing the logo:
- the light theme switches to **Dark Theme**
- black background
- white text
- white shadow and glow effects on categories and achievements instead of black
- UI elements adapt to dark-mode design

Pressing the logo again switches back to light mode.

---

## Error Messages and Feedback

The system may display the following messages:

### During Registration
- missing field
- passwords do not match
- email already taken

### During Login
- incorrect username or password
- missing field

### Achievements
- only logged-in users can mark achievements as “completed”
